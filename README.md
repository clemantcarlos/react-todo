## 📋 About the Project

React Todo is a modern task management application built with the latest versions of React 19, Vite 8, and Tailwind CSS 4. It features task creation, filtering by status (todo/in-progress/done), search functionality, and a drawer-based task creation interface. Notably, it uses the experimental React Compiler for automatic memoization.

## ✨ Features

| Feature | Description |
|---------|-------------|
| Task Management | Create, view, and manage tasks |
| Status Filtering | Filter tasks by todo, in-progress, done |
| Search | Search tasks by title |
| Task Drawer | Slide-out panel for task creation |
| React Compiler | Experimental automatic memoization |
| Tailwind CSS 4 | Latest utility-first styling |
| TypeScript | Full type safety |

## 🛠️ Tech Stack

- **Framework:** React 19.2 with TypeScript
- **Build Tool:** Vite 8 with Rolldown
- **Styling:** Tailwind CSS 4
- **Compiler:** Experimental React Compiler (babel-plugin-react-compiler)
- **Linting:** ESLint 10

## 🚀 Getting Started

### Prerequisites

- Node.js >= 18
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/react-todo.git
cd react-todo

# Install dependencies
npm install
```

### Running the Application

```bash
npm run dev          # Start development server
npm run build        # Build for production
npm run preview      # Preview production build
npm run lint         # Run ESLint
```
